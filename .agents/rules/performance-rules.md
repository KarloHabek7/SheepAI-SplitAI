# Performance Rules

> The app must feel fast during the live demo. Judges notice loading delays and layout shifts.

1. **Images must be WebP format.** All raster images (PNG, JPEG) generated by AI models must be converted to WebP before committing. Maximum file size: **200 KB** per image.

2. **Videos must be web-optimized.** Use WebM as primary format with MP4 fallback. Maximum file size: **1.5 MB** per video clip. All videos must be 720p, 5-second loops.

3. **Lazy-load below-the-fold images.** Every `<img>` tag below the initial viewport must use `loading="lazy"`. Only the hero/above-the-fold image loads eagerly.

   ```tsx
   // ✅ DO
   <img src="/assets/images/feature-1.webp" alt="AI analytics dashboard" loading="lazy" />

   // ❌ DON'T (for below-fold images)
   <img src="/assets/images/feature-1.png" alt="image" />
   ```

4. **Bundle size awareness.** Before adding a new dependency, check its bundle size. Prefer lightweight alternatives:
   - Use `lucide-react` over `react-icons` (tree-shakeable)
   - Use native `fetch` over `axios`
   - Use CSS animations over JS animation libraries when possible

5. **No unnecessary re-renders.** Use `React.memo()` for components that receive stable props. Use `useCallback` and `useMemo` for expensive computations or callbacks passed to child components.

6. **Code splitting for routes.** Use `React.lazy()` and `Suspense` for route-level code splitting. Each page should be a separate chunk.

   ```tsx
   // ✅ DO
   const Dashboard = React.lazy(() => import('@/pages/Dashboard'));
   <Suspense fallback={<LoadingSpinner />}>
     <Dashboard />
   </Suspense>
   ```

7. **Descriptive alt text is required.** Every `<img>` must have a meaningful `alt` attribute. Placeholder `alt="image"` is forbidden. This is both an accessibility and SEO requirement.

8. **Video elements must have correct attributes.** Background videos must include `autoPlay`, `muted`, `loop`, and `playsInline` to ensure autoplay works across all browsers without user interaction.

### DO / DON'T

```
✅ DO: Convert hero-bg.png to hero-bg.webp (under 200KB) before committing
❌ DON'T: Commit a 2MB PNG file to app/public/assets/images/

✅ DO: <img alt="AI-powered sheep monitoring dashboard showing real-time analytics" />
❌ DON'T: <img alt="image" /> or <img /> (missing alt)

✅ DO: Use CSS transition for hover effects
❌ DON'T: Import framer-motion just for a simple fade-in
```
