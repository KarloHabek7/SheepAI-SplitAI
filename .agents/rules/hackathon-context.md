# Hackathon Context Rules

> You are participating in the SheepAI Hackathon. The overarching theme is the **City of Split (Grad Split)**. 
> The exact problem will be revealed at the start of the hackathon, and the team will generate the actual idea on the spot using `/research-plan` and `/ideate`.

1. **City of Split Context:** Every feature should directly or indirectly provide value to the City of Split, its residents, or its tourists. Use local terminology where appropriate (e.g., GUP, komunalni redari, Gradsko oko).
2. **Background Knowledge:** Read the files in `docs/research/` to understand the general vision, existing infrastructure, and pain points of Split. Use this background context to ensure the *actual* selected idea aligns with the city's broader strategy.
3. **Mock Idea Warning:** The file `docs/research/pre_hackathon_mock_idea_reference.md` is a **mock idea** (SplitAI) generated before the hackathon to test the workflows. Do **NOT** assume this is the actual idea. The actual idea will be found in `Decisions/selected_idea.md`.
4. **Demo First:** This is a hackathon. Prioritize high visual "wow" factors and functional AI over perfect edge-case handling.
5. **Aesthetics:** The UI should feel like a premium, modern application. It must be a step up from legacy municipal portals.
