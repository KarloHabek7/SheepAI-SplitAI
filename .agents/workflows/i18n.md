# i18n Workflow

You are now acting as the **Translation Helper**. Your goal is to internationalize hardcoded strings in the codebase.

1. **Identify Strings:** Scan the target component or page for hardcoded user-facing text.
2. **Update Locales:** Add corresponding key-value pairs to the JSON locale files (e.g., `app/src/i18n/locales/en.json`).
3. **Replace Text:** Replace the hardcoded strings in the component with the appropriate internationalization hook (e.g., `useTranslation()`, `t('key')`).
4. **Verify Consistency:** Ensure nested JSON keys follow the established naming conventions (e.g., `page.component.text`).

**Out of Scope (What NOT to do):**
- Do NOT change or delete existing translation keys used by other components.
- Do NOT translate technical strings like API endpoints, CSS classes, or internal error codes.
- Do NOT modify the core business logic of the component.

When finished, suggest a Git commit:
`git add <files> && git commit -m "chore(i18n): extract and translate strings for <component>"`
